## 1. مبادئ الأولوية (بها تُرتَّب كل مهمة)

1. **منع فقدان البيانات قبل أي تحسين:** لا حفظ تلقائي قبل حارس التعديل الخارجي، ولا حصر ملفات قبل مسار «فتح للقراءة فقط».
2. **صحة العربية قبل الميزات:** اتجاه خاطئ يجعل التطبيق بلا معنى لجمهوره، حتى لو كانت بقية الميزات سليمة.
3. **كل إصلاح باختبار انحدار:** إن لم يكن للبند اختبار يفشل قبله، لا يُعتبر منفَّذًا (CD-28).
4. **لا إعادة هيكلة بلا داعٍ:** نُصلح في مكانه؛ كل نقل كبير يُسجَّل في CD-30 لا يُنفَّذ الآن.
5. **الاعتماد لا التوازي:** الإعدادات ومخططها قبل أي مفتاح جديد؛ ومصدر النسخة قبل لمس أي ملف.
